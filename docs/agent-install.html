ติดตั้ง NN-LRMS agent บนเครื่องห้องคลอด

โปรแกรมเล็ก ๆ ที่ดึงข้อมูลห้องคลอดจาก HOSxP ของโรงพยาบาล แล้วส่งเข้าเซิร์ฟเวอร์ NN-LRMS — ทำงานอัตโนมัติตลอด 24 ชั่วโมง โดยไม่ต้องมีคนเปิดเบราว์เซอร์

ทำไมต้องมี

โดยค่าเริ่มต้น NN-LRMS ดึงข้อมูลจาก HOSxP ผ่าน เบราว์เซอร์ ของคนที่เปิดหน้า NN-LRMS ไว้ ถ้าไม่มีใครเปิดหน้าจอ (กลางคืน วันหยุด หรือไม่มีใครใช้เครื่อง) แดชบอร์ดภาพรวมจังหวัดจะไม่มีตัวเลขใหม่ ส่วน หน้าห้องคลอด ที่เปิดจาก HOSxP ยังเห็นข้อมูลสดเสมอ เพราะอ่าน HOSxP โดยตรง

agent คือเบราว์เซอร์แบบไม่ต้องมีคนเปิด — รันบนเครื่องห้องคลอดตลอด เชื่อมต่อผ่าน BMS gateway ในเครื่อง (ไม่โดนจำกัดจำนวนครั้งต่อวินาที และได้ข้อมูลจริง ไม่ถูกสุ่ม CID/HN) ดึงทุก 5 นาที

1. ไฟล์ที่ได้รับ

nn-lrms-agent.exeตัว agent (ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร)
NN-LRMS-agent-service.exeWinSW (ตัวห่อให้เป็น service)
NN-LRMS-agent-service.xmlนิยาม service
agent.example.jsonแม่แบบไฟล์ตั้งค่า
check.cmdตรวจว่าเครื่องพร้อม
install-service.cmdติดตั้ง service
uninstall-service.cmdถอน service
diagnose.cmdรวบรวมอาการเพื่อหาสาเหตุ (ได้ diagnose-report.txt)
INSTALL-GUIDE.htmlคู่มือนี้
VERSION.txtเวอร์ชัน
SHA256SUMS.txtchecksum ของไฟล์ทุกไฟล์

คัดลอกทั้งโฟลเดอร์ไปไว้ที่ เช่น C:\NN-LRMS-agent\ (ต้องเป็น path ที่ไม่มีชื่อผู้ใช้ปนอยู่)

2. ใส่ค่าตั้ง

คัดลอก agent.example.json เป็น agent.config.json แล้วแก้ 3 ค่านี้

คีย์ค่าหมายเหตุ
serverUrlเช่น https://kk-lrms.bmscloud.in.thเซิร์ฟเวอร์ NN-LRMS
apiKeykklrms_...ขอจากผู้ดูแลระบบส่วนกลาง (คีย์แสดงครั้งเดียว)
gatewayTokenโทเคนของ BMS gateway บนเครื่องนี้ขอจาก IT ของ รพ. — เป็นของเครื่องนี้ ไม่ใช่ของจากเซิร์ฟเวอร์
intervalMinutes5ดึงทุกกี่นาที
ไฟล์นี้มีความลับ — ปิดสิทธิ์อ่านไฟล์ให้เฉพาะบัญชีที่จะรัน service เท่านั้น

3. ตรวจว่าเครื่องพร้อม

คลิกขวา check.cmd → Run as administrator

== 1/5 ไฟล์ตั้งค่า ==                      OK — serverUrl=... localGateway=...
== 2/5 ตัว agent และตำแหน่งโฟลเดอร์ ==     OK — พบ nn-lrms-agent.exe
== 3/5 BMS gateway บนเครื่องนี้ + PasteJSON == OK — PasteJSON (hosxp.net) แลก session สำเร็จ
== 4/5 เซิร์ฟเวอร์ NN-LRMS (/api/health) ==    OK — HTTP 200
== 5/5 สิทธิ์ API Key (/api/sync/agent-push) == OK — API Key ใช้งานได้ (HTTP 200)

ผ่านทุกข้อจึงไปขั้นตอนถัดไปได้ ถ้าข้อไหน FAIL ให้ดูหัวข้อ "เจอปัญหา" ท้ายคู่มือ

4. ติดตั้งเป็น service

คลิกขวา install-service.cmd → Run as administrator จะสั่ง install + start แล้วรอตรวจสถานะ RUNNING ให้

service จะเริ่มอัตโนมัติเมื่อเปิดเครื่อง และ restart เอง 2 ครั้งถ้าตัว agent ล้ม (30 วินาที และ 60 วินาที) แล้วหยุดให้ IT ตรวจจาก log

NN-LRMS-agent-service.exe status
Get-Content .\logs\NN-LRMS-agent-service.out.log -Tail 50

ในหน้า NN-LRMS: ตั้งค่า → สถานะการซิงค์ คอลัมน์ "เริ่มโดย" ของโรงพยาบาลนี้ต้องขึ้น agent ที่ รพ. พร้อมสถานะ agent v... · local และเวลา "ซิงค์ล่าสุด" ต้องเดินเรื่อย

5. ถอนการติดตั้ง

คลิกขวา uninstall-service.cmd → Run as administrator

ห้ามแก้ข้อมูลคนไข้ใน HOSxP เพื่อให้แดชบอร์ดมีตัวเลข — ถ้าผู้คลอดรับเข้าด้วยประเภทการรับเข้าที่ไม่ใช่ "คลอดบุตร" ระบบจะไม่นับให้ ให้แก้ ประเภทการรับเข้า ใน HOSxP ให้ถูกต้องแทน
