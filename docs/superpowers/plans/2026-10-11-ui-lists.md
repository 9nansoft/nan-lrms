# Provincial List Pages Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `/hospitals`, `/pregnancies`, `/referrals` and `/outcomes` on one shared, Thai-first list-page pattern, and re-chrome their two detail pages on the same blocks. Tables must fit or wrap at every width, no page may scroll sideways, and hospital status words must be Thai everywhere outside the kiosk.

**Architecture:**
- **Vocabulary.** `src/config/hospital-status.ts` is the one place that turns `connectionStatus` + `syncStatus` into words, tones and frozen kiosk strings. The map, `HospitalTable`, `ConnectionStatus`, `ConnectionSummary`, `InactiveHospitalList` and `/hospitals` read it.
- **Pattern.** The list pattern is built once, then the pages compose it:
  - `ListPageLayout`: `@container` root, stale banner, `PageHeader`.
  - `KpiGrid` + `KpiTile` (now with a toggle mode).
  - The `FilterBar` family.
  - `ResponsiveTable`: `DataTable` above a container width, cards below.
  - `Pagination`.
  - `useDebouncedSearch` and `useListData`.
- **Roster logic.** Pure roll-ups move to `src/services/hospital-roster.ts`.
- **Detail pages.** They get chrome-level adoption (spec L10): `PageHeader`, `KpiGrid`, `SectionCard`, a container-query layout, no `zoom`.

**Tech Stack:** Next.js 16 App Router, React 19.2, Tailwind CSS 4 (`@theme`, built-in container queries `@container` / `@min-[Npx]:`), shadcn/ui + Base UI tooltip, SWR, lucide-react, Leaflet, Vitest + RTL (jsdom), Playwright, ESLint 9 flat config.

**Spec:** `docs/superpowers/specs/2026-10-11-ui-lists-design.md`. Read it first. Also read the foundation spec/plan (`docs/superpowers/specs/2026-10-11-ui-foundation-design.md`, `docs/superpowers/plans/2026-10-11-ui-foundation.md`) and the dashboard spec (`docs/superpowers/specs/2026-10-11-ui-dashboard-design.md`), whose D6, D11 and D12 this plan reuses.

## Global Constraints

- Font: Sarabun (already loaded in `src/app/layout.tsx`); do not add fonts.
- Minimum text size outside kiosk: **13px** (`text-caption`).
- Type scale (px / line-height / weight):
  - caption 13/1.5/400
  - label 14/1.5/500
  - body 15/1.65/400
  - body-lg 17/1.6/500
  - title 22/1.35/600
  - page 26/1.3/700
  - kpi-sm 26/1.15/700
  - kpi 34/1.15/700
- Colours (exact hex, from the spec):
  - Surfaces: surface-page `#FBF8F3`, surface-card `#FFFFFF`, surface-muted `#F3EFE6`, border `#E8E1D2`
  - Ink: ink `#22223B`, ink-muted `#5C5C7A`, ink-subtle `#6B6B85`
  - Brand: brand `#2E3A87`, brand-strong `#232D6B`, brand-soft `#E4E6F4`

  - Risk medium: `#D08A00` / text `#8A5A00` / tint `#FFF6E0`
  - Risk low: `#3F8F4F` / text `#2F6B3A` / tint `#EEF7EE`
  - Status `ok` / `warn` / `danger` alias risk low / medium / high.
- Every declared text/background pair ≥ 4.5:1. On `surface-muted`, secondary text uses `ink-muted`, never `ink-subtle`. Chips use `*-text` on `*-tint`, never a marker colour as text.
- `html { font-size: 18px }` stays. The type scale is in **px**. **Compute container widths with an 18px rem:** `px-4` = 18px, `px-6` = 27px, `p-5` = 22.5px, `gap-5` = 22.5px, `h-10` = 45px. **Media-query breakpoints use the 16px initial size:** Tailwind `md:` = 768px viewport, `lg:` = 1024px viewport. Prefer container queries (`@min-[Npx]:`, px are real px) over viewport breakpoints.
- KPI numbers come from server aggregates, never `rows.length` of a row-limited fetch (count-provenance rule). The `/api/dashboard` hospital list is complete and unpaginated, so sums of its per-hospital `counts`/`ancCounts` are server aggregates.

### Spec deviations (decided while planning, with reasons)

The design-level deviations L1–L13 are in the spec. These are the plan-level ones:

1. **Stale-data banners on `/pregnancies`, `/referrals` and `/outcomes`.** Today these pages keep showing cached rows after a failed refresh, with nothing on screen to say so. That is a Constitution VI bug ("Offline: display cached data with Last sync"). `ListPageLayout.stale` now shows the banner, the same way `/hospitals` already does.
2. **`useDebouncedSearch` commits only when the trimmed term changed.** Today the effect also fires on mount and calls `setPage(1)` while the page is already 1. The visible results are identical, and the change removes a redundant render.
3. **Four copy fixes found while reading the code.** All four are copy-only:
   - `/referrals` "ค้างเกิน 24 ชม." becomes `REFERRAL_SLA.overdueAfterHours`.
   - `/pregnancies` copy "60 วัน" / "14 วัน" / "42 สัปดาห์" becomes `ANC_LAST_VISIT_MAX_AGE_DAYS` / `ANC_EDC_MAX_PAST_DAYS` / `ANC_MAX_GA_WEEKS`.
   - `/outcomes` uses `NEWBORN_THRESHOLDS` instead of `2500` / `7` in `BirthRow`. That function decides the LBW and low-Apgar flags, so this one is the same rule, sourced once.
   - The hospital-console literals `14` / `7` (days) and `34` (GA) become named config or constants with the same values.
4. **`SectionCard` gains `testId`.** Page tests locate `corridors-panel`, `daily-volume`, `outcome-trend` and `hospital-outcomes` by test id.
5. **`/hospitals` roster column is 640px in the two-column layout.** At 1440px that leaves about 595px inside the card, minus a 15px scrollbar, which is at least the 560px `sm` table breakpoint. The map column gets about 476px, about the dashboard's 400px panel plus margin.

## Review Focus

1. **No page-level horizontal scroll.** The E2E check in Task 8 measures every list and detail page at 1440, 1024 and 768. The roster check asserts that each row's last cell ends inside the roster card at 1440, which is the original finding.
2. **Count provenance.** Every KPI and "ทั้งหมด N" traces to `pagination.total`, `counts`, `opsCounts`, `statusCounts`, `totalBirths` or `summarizeRoster()` over the complete hospital list. Tasks 3–5 each include a `.length` grep; Task 6 pins the console aggregates in its characterization test.
3. **No interactive nesting and no double navigation.** The `KpiTile` toggle is a stretched button with the hint as a sibling. A click on the `DataTable` row's inner `<Link tabIndex={-1}>` must not also fire `onRowClick`. Both are pinned in Task 2.
4. **The kiosk is unchanged.** `KioskDashboard.test.tsx` stays untouched. The kiosk legend, tooltip and pin titles are pinned verbatim in Task 1.
5. **Thai copy accuracy.** Every label states what the number counts, with thresholds from config. The hospital-console "ห่างนัด ANC ≥ 14 วัน" keeps its legacy threshold; it now lives in config (spec L13).

```ts
// tests/unit/config/hospital-status.test.ts
import { describe, it, expect } from 'vitest';
import {
  classifyHospitalLink,
  CONNECTION_LABEL_TH,
  HOSPITAL_LINK_STATUS,
  hospitalLinkText,
  kioskLinkText,
  MAP_LEGEND,
  SYNC_HEALTH_TH,
} from '@/config/hospital-status';
import { SYNC_HEALTH } from '@/config/hospital-network';
import { ConnectionStatus } from '@/types/domain';

// The three legacy inline chains this module replaces, copied verbatim from
// ProvinceMapLeaflet (pin dot + tooltip) and HospitalTable (badge) before the
// refactor. classifyHospitalLink must agree with every one of them.
function legacyTable(conn: string, sync: string) {
  const isBlocked = sync === 'BLOCKED';
  const isNever = sync === 'NEVER_SYNCED';
  const isOnline = conn === 'ONLINE';
  const isOffline = conn === 'OFFLINE';
  return isBlocked ? 'BLOCKED' : isNever && !isOffline ? 'NO SYNC' : isOnline ? 'ONLINE' : isOffline ? 'OFFLINE' : 'UNKNOWN';
}
function legacyTooltip(conn: string, sync: string) {
  const isBlocked = sync === 'BLOCKED';
  const isNever = sync === 'NEVER_SYNCED';
  return isBlocked ? 'BLOCKED' : conn === 'ONLINE' && !isNever ? 'ONLINE' : conn === 'OFFLINE' ? 'OFFLINE' : isNever ? 'NO SYNC' : 'UNKNOWN';
}

const CONNS = ['ONLINE', 'OFFLINE', 'UNKNOWN'];
const SYNCS = ['OK', 'BLOCKED', 'NEVER_SYNCED'];

describe('classifyHospitalLink', () => {
  it.each(CONNS.flatMap((c) => SYNCS.map((s) => [c, s] as const)))(
    '%s + %s matches the legacy badge and tooltip precedence',
    (conn, sync) => {
      const status = classifyHospitalLink(conn, sync);
      expect(HOSPITAL_LINK_STATUS[status].kioskLabel).toBe(legacyTable(conn, sync));
      expect(HOSPITAL_LINK_STATUS[status].kioskLabel).toBe(legacyTooltip(conn, sync));
    },
  );

  it('treats missing values as unknown / never synced', () => {
    expect(classifyHospitalLink(undefined, undefined)).toBe('unknown');
    expect(classifyHospitalLink('ONLINE', 'NEVER_SYNCED')).toBe('noSync');
  });
});

describe('Thai words', () => {
  it('uses the app connection words and shares sync words across vocabularies', () => {
    expect(HOSPITAL_LINK_STATUS.online.labelTh).toBe('ออนไลน์');
    expect(HOSPITAL_LINK_STATUS.offline.labelTh).toBe('ออฟไลน์');
    expect(HOSPITAL_LINK_STATUS.unknown.labelTh).toBe('ไม่ทราบ');
    expect(SYNC_HEALTH_TH.blocked).toBe(HOSPITAL_LINK_STATUS.blocked.labelTh);
    expect(SYNC_HEALTH_TH.never).toBe(HOSPITAL_LINK_STATUS.noSync.labelTh);
    expect(CONNECTION_LABEL_TH[ConnectionStatus.ONLINE]).toBe('ออนไลน์');
    expect(CONNECTION_LABEL_TH[ConnectionStatus.OFFLINE]).toBe('ออฟไลน์');

    expect(SYNC_HEALTH_TH.stale).toContain(String(SYNC_HEALTH.staleAfterMinutes));
    expect(SYNC_HEALTH_TH.critical).toContain(String(SYNC_HEALTH.criticalAfterHours));
    for (const v of Object.values(SYNC_HEALTH_TH)) expect(v).not.toContain('ซิงก์');

    expect(hospitalLinkText('blocked', 'missing_marketplace_token')).toEqual({

      detail: 'ระบบระงับการซิงค์ของโรงพยาบาลนี้ — missing_marketplace_token',

    expect(hospitalLinkText('blocked', null).detail).toContain('ไม่ทราบสาเหตุ');
    expect(hospitalLinkText('online').label).toBe('ออนไลน์');
  });
});

describe('kiosk copy is frozen verbatim', () => {
  it('pin titles keep the legacy never-synced-first precedence', () => {
    expect(kioskLinkText('OFFLINE', 'NEVER_SYNCED').pinTitle).toBe('ยังไม่เคยมีการเชื่อมต่อ Sync');
```

```ts
export type HospitalLinkStatus = 'online' | 'blocked' | 'offline' | 'noSync' | 'unknown';
export type StatusTone = 'ok' | 'warn' | 'danger' | 'neutral';

/** Same precedence as the inline chains it replaces (map pin dot, map
 *  tooltip, HospitalTable badge): BLOCKED wins over a live tunnel, and a
 *  tunnel that is up but has never synced is not "online". */
export function classifyHospitalLink(
  connectionStatus: string | null | undefined,
  syncStatus: string | null | undefined,
): HospitalLinkStatus {
  if (syncStatus === 'BLOCKED') return 'blocked';
  const neverSynced = syncStatus === 'NEVER_SYNCED';
  if (connectionStatus === ConnectionStatus.ONLINE && !neverSynced) return 'online';
  if (connectionStatus === ConnectionStatus.OFFLINE) return 'offline';
  if (neverSynced) return 'noSync';
  return 'unknown';
}

export interface HospitalLinkMeta {
  labelTh: string;
  detailTh: string;
  tone: StatusTone;
  /** Frozen kiosk / legacy badge word — do not translate. */
  kioskLabel: string;
}

export const HOSPITAL_LINK_STATUS: Record<HospitalLinkStatus, HospitalLinkMeta> = {
  online: { labelTh: 'ออนไลน์', detailTh: 'เชื่อมต่อและซิงค์ข้อมูลปกติ', tone: 'ok', kioskLabel: 'ONLINE' },
  blocked: { labelTh: 'ระงับการซิงค์', detailTh: 'ระบบระงับการซิงค์ของโรงพยาบาลนี้', tone: 'warn', kioskLabel: 'BLOCKED' },
  offline: { labelTh: 'ออฟไลน์', detailTh: 'ติดต่อตู้ BMS ของโรงพยาบาลไม่ได้', tone: 'danger', kioskLabel: 'OFFLINE' },
  noSync: {

    tone: 'neutral',
    kioskLabel: 'NO SYNC',
  },
  unknown: { labelTh: 'ไม่ทราบ', detailTh: 'ยังไม่ทราบสถานะการเชื่อมต่อ', tone: 'neutral', kioskLabel: 'UNKNOWN' },
};

/** Light-mode label + detail (Thai). Blocked appends the server's reason. */
export function hospitalLinkText(
  status: HospitalLinkStatus,
  blockedReason?: string | null,
): { label: string; detail: string } {
  const m = HOSPITAL_LINK_STATUS[status];
  const detail = status === 'blocked' ? `${m.detailTh} — ${blockedReason ?? 'ไม่ทราบสาเหตุ'}` : m.detailTh;
  return { label: m.labelTh, detail };
}

/** Frozen kiosk / legacy strings, each with ITS OWN legacy precedence (the
 *  pin title and tooltip detail check never-synced before the connection).
 *  Byte-identical to ProvinceMapLeaflet / HospitalTable before UI
 *  sub-project 4 — do not "fix" the precedence here. */
export function kioskLinkText(
  connectionStatus: string | null | undefined,
  syncStatus: string | null | undefined,
  blockedReason?: string | null,
): { label: string; detail: string; pinTitle: string; tableTitle: string } {
  const isBlocked = syncStatus === 'BLOCKED';
  const isNever = syncStatus === 'NEVER_SYNCED';
  const label = HOSPITAL_LINK_STATUS[classifyHospitalLink(connectionStatus, syncStatus)].kioskLabel;
  const detail = isBlocked
    ? `Sync ถูกระงับ — ${blockedReason ?? 'unknown'}`
    : isNever
      ? 'ยังไม่เคยเชื่อม sync'
      : connectionStatus === 'OFFLINE'
        ? 'ติดต่อตู้ BMS ไม่ได้'
        : connectionStatus === 'ONLINE'
          ? 'sync ปกติ'
          : 'ยังไม่ทราบสถานะ';
  const pinTitle = isBlocked
    ? `Sync ถูกระงับ — ${blockedReason ?? 'unknown'}`
    : isNever
      ? 'ยังไม่เคยมีการเชื่อมต่อ Sync'
      : connectionStatus === 'ONLINE'
        ? 'Online'
        : connectionStatus === 'OFFLINE'
          ? 'Offline'
          : 'Unknown';
  const tableTitle = isBlocked
    ? `Sync ถูกระงับ — ${blockedReason ?? 'unknown reason'}`
    : isNever
      ? 'ยังไม่เคยมีการเชื่อมต่อ Sync — รอผู้ใช้จากโรงพยาบาลนี้เปิด KK-LRMS ครั้งแรก'
      : '';
  return { label, detail, pinTitle, tableTitle };
}
```

```ts
// src/hooks/useDebouncedSearch.ts
// Search box state for server-side search: `search` follows every keystroke;
// `query` (trimmed) is committed after a pause and is what goes into the API
// key. `onCommit` runs on each commit (lists reset to page 1). It must be
// stable (wrap it in useCallback).
'use client';
import { useEffect, useState } from 'react';
import { LIST_PAGE } from '@/config/list-page';

export function useDebouncedSearch(onCommit: () => void, delayMs: number = LIST_PAGE.searchDebounceMs) {
  const [search, setSearch] = useState('');
  const [query, setQuery] = useState('');

  useEffect(() => {
    const term = search.trim();
    if (term === query) return;
    const handle = setTimeout(() => {
      setQuery(term);
      onCommit();
    }, delayMs);
    return () => clearTimeout(handle);
  }, [search, query, delayMs, onCommit]);

  const clear = () => {
    setSearch('');
    setQuery('');
  };

  return { search, setSearch, query, clear };
}
```

```ts
// SWR for list pages: refresh interval + keepPreviousData (paging/filtering

'use client';
import { useState } from 'react';

export function useListData<T>(key: string | null, refreshMs: number) {
  const [lastUpdatedAt, setLastUpdatedAt] = useState<string | null>(null);
```

```ts
// src/services/hospital-roster.ts
// Pure roster logic for /hospitals (UI sub-project 4). The input is the
// /api/dashboard hospital list — complete and unpaginated — so every sum here
// is a sum of per-hospital server aggregates (count-provenance rule).
// Client-safe: config imports only.
import { HOSPITAL_LEVELS, KK_HOSPITALS } from '@/config/hospitals';
import {
  classifyPartographCoverage,
  classifySyncHealth,
  combinedWorkload,
  type PartographCoverageClass,
  type SyncHealthClass,
} from '@/config/hospital-network';
import { HospitalLevel } from '@/types/domain';
import type { DashboardHospital } from '@/types/api';

const KK_HCODES = new Set(KK_HOSPITALS.map((h) => h.hcode));

export type RosterArea = 'khonkaen' | 'other';

export function rosterArea(h: Pick<DashboardHospital, 'hcode'>): RosterArea {
  return KK_HCODES.has(h.hcode) ? 'khonkaen' : 'other';
}

/** Name or hcode contains the term (case-insensitive). Blank → same array. */
export function searchRoster(hospitals: DashboardHospital[], term: string): DashboardHospital[] {
  const q = term.trim().toLowerCase();
  if (!q) return hospitals;
  return hospitals.filter((h) => h.name.toLowerCase().includes(q) || h.hcode.toLowerCase().includes(q));
}

export interface RosterSummary {
  hospitals: number;
  withWorkload: number;
  sync: Record<SyncHealthClass, number>;
  /** stale + critical + never + blocked */
  syncAttention: number;
  anc: number;
  ancHr3: number;
  labor: { total: number; low: number; medium: number; high: number };
  parto: { recent: number; charted: number; cls: PartographCoverageClass; pct: number | null; below: number };
}

export function summarizeRoster(hospitals: DashboardHospital[], now: Date = new Date()): RosterSummary {
  const sync: Record<SyncHealthClass, number> = { ok: 0, stale: 0, critical: 0, never: 0, blocked: 0 };
  const labor = { total: 0, low: 0, medium: 0, high: 0 };
  let anc = 0;
  let ancHr3 = 0;
  let recent = 0;
  let charted = 0;
  let below = 0;
  let withWorkload = 0;
  for (const h of hospitals) {
    sync[classifySyncHealth(h.syncStatus, h.lastSyncAt, now)] += 1;
    labor.total += h.counts.total;
    labor.low += h.counts.low;
    labor.medium += h.counts.medium;
    labor.high += h.counts.high;
    anc += h.ancCounts.total;
    ancHr3 += h.ancCounts.hr3;
    recent += h.partographQuality.laborRecent;
    charted += h.partographQuality.withPartograph;
    const cls = classifyPartographCoverage(h.partographQuality.laborRecent, h.partographQuality.withPartograph);
    if (cls === 'warn' || cls === 'critical') below += 1;
    if (combinedWorkload(h.counts, h.ancCounts) > 0) withWorkload += 1;
  }
  return {
    hospitals: hospitals.length,
    withWorkload,
    sync,
    syncAttention: sync.stale + sync.critical + sync.never + sync.blocked,
    anc,
    ancHr3,
    labor,
    parto: {
      recent,
      charted,
      cls: classifyPartographCoverage(recent, charted),
      pct: recent > 0 ? Math.round((charted / recent) * 100) : null,
      below,
    },
  };
}

export interface RosterGroup {
  level: HospitalLevel;
  nameTh: string;
  hospitals: DashboardHospital[];
  stats: { anc: number; labor: number; high: number };
}

/** Level groups in HOSPITAL_LEVELS sort order, busiest first inside each
 *  (combined labour + weighted-ANC workload). A level missing from
 *  HOSPITAL_LEVELS falls into M2, as before. Empty groups are dropped. */
export function groupRosterByLevel(hospitals: DashboardHospital[]): RosterGroup[] {
  const order = Object.values(HOSPITAL_LEVELS).sort((a, b) => a.sortOrder - b.sortOrder);
  const buckets = new Map<HospitalLevel, DashboardHospital[]>(order.map((c) => [c.level, []]));
  for (const h of hospitals) (buckets.get(h.level) ?? buckets.get(HospitalLevel.M2))?.push(h);
  const groups: RosterGroup[] = [];
  for (const cfg of order) {
    const list = buckets.get(cfg.level) ?? [];
    if (list.length === 0) continue;
    const sorted = [...list].sort(
      (a, b) => combinedWorkload(b.counts, b.ancCounts) - combinedWorkload(a.counts, a.ancCounts),
    );
    const stats = { anc: 0, labor: 0, high: 0 };
    for (const h of sorted) {
      stats.anc += h.ancCounts.total;
      stats.labor += h.counts.total;
      stats.high += h.counts.high;
    }
    groups.push({ level: cfg.level, nameTh: cfg.nameTh, hospitals: sorted, stats });
  }
  return groups;
}
```

```tsx
const SYNC_DOT: Record<SyncHealthClass, string> = {
  ok: 'bg-ok',
  stale: 'bg-warn',
  critical: 'bg-danger',
  never: 'bg-ink-subtle',
  blocked: 'bg-danger',
};
const SYNC_TEXT: Record<SyncHealthClass, string> = {
  ok: 'text-ink-muted',
  stale: 'text-warn-text',
  critical: 'text-danger-text',
  never: 'text-ink-muted',
  blocked: 'text-danger-text',
};
const PARTO_TEXT: Record<PartographCoverageClass, string> = {
  ok: 'text-ok-text',
  warn: 'text-warn-text',
  critical: 'text-danger-text',
  none: 'text-ink-muted',
};

/** Relative last-sync age with a status dot; blocked / never get their words. */
function SyncCell({ hospital }: { hospital: DashboardHospital }) {
  const health = classifySyncHealth(hospital.syncStatus, hospital.lastSyncAt);
  const text =
    health === 'blocked' || health === 'never' ? SYNC_HEALTH_TH[health] : formatRelativeAge(hospital.lastSyncAt, 'th');
  return (
    <span
      className={cn('inline-flex items-center gap-1.5 text-label tabular-nums', SYNC_TEXT[health])}
      title={hospital.syncBlockedReason ?? SYNC_HEALTH_TH[health]}
    >
      <span aria-hidden="true" className={cn('h-2 w-2 shrink-0 rounded-full', SYNC_DOT[health])} />
      {text}
    </span>
  );
}

/** Partograph coverage "charted/recent" over the quality window; "—" when no
 *  recent admissions. */
function PartoCell({ hospital }: { hospital: DashboardHospital }) {
  const pq = hospital.partographQuality;
  const cls = classifyPartographCoverage(pq.laborRecent, pq.withPartograph);
  return (
    <span
      data-testid="parto-cell"
      data-parto={cls}
      className={cn('text-label font-semibold tabular-nums', PARTO_TEXT[cls])}
      title={
        cls === 'none'
          ? `ไม่มีผู้คลอดรับใหม่ใน ${PARTOGRAPH_QUALITY.windowDays} วัน`
          : `บันทึกพาร์โทกราฟ ${pq.withPartograph} จาก ${pq.laborRecent} ราย (${PARTOGRAPH_QUALITY.windowDays} วัน)`
      }
    >
      {cls === 'none' ? '—' : `${pq.withPartograph}/${pq.laborRecent}`}
    </span>
  );
}

function HospitalName({ hospital: h, asLink }: { hospital: DashboardHospital; asLink: boolean }) {
  return (
    <div className="flex min-w-0 flex-col gap-0.5">
      <span className="flex flex-wrap items-center gap-1.5">
        {asLink ? (
          // tabIndex -1: the row is the keyboard target; the link keeps
          // middle-click / open-in-new-tab (spec L2).
          <Link href={`/hospitals/${h.hcode}`} tabIndex={-1} className="text-body font-semibold text-ink hover:underline">
            {h.name}
          </Link>
        ) : (
          <span className="text-body font-semibold text-ink">{h.name}</span>
        )}
        {h.counts.high > 0 && <FlagChip tone="danger">เสี่ยงสูง {h.counts.high}</FlagChip>}
        {h.ancCounts.hr3 > 0 && (
          <FlagChip tone="warn" title={`ครรภ์เสี่ยงสูง (HR3) ${h.ancCounts.hr3} ราย`}>
            HR3 {h.ancCounts.hr3}
          </FlagChip>
        )}
      </span>
      <span className="text-caption tabular-nums text-ink-muted">รหัส {h.hcode}</span>
    </div>
  );
}

const dash = (n: number) => (n > 0 ? n.toLocaleString('en-US') : '—');

const ROSTER_COLUMNS: DataTableColumn<DashboardHospital>[] = [
  { key: 'name', header: 'โรงพยาบาล', className: 'min-w-[160px]', cell: (h) => <HospitalName hospital={h} asLink /> },
  { key: 'anc', header: 'ANC', numeric: true, cell: (h) => dash(h.ancCounts.total) },
  { key: 'labor', header: 'ห้องคลอด', numeric: true, cell: (h) => dash(h.counts.total) },
  { key: 'parto', header: 'พาร์โทกราฟ', numeric: true, cell: (h) => <PartoCell hospital={h} /> },
  { key: 'sync', header: 'ซิงค์ล่าสุด', cell: (h) => <SyncCell hospital={h} /> },
];

function RosterCard({
  hospital: h,
  selected,
  onHover,
}: {
  hospital: DashboardHospital;
  selected: boolean;
  onHover: () => void;
}) {
  return (
    <Link
      href={`/hospitals/${h.hcode}`}
      data-testid={`hospital-card-${h.hcode}`}
      data-hcode={h.hcode}
      onPointerEnter={onHover}
      className={cn(
        'block rounded-xl border border-border px-3 py-2.5 hover:bg-surface-muted focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-brand',
        selected && 'bg-brand-soft',
      )}
    >
      <HospitalName hospital={h} asLink={false} />
      <div className="mt-1.5 flex flex-wrap items-center gap-x-4 gap-y-1 text-label text-ink-muted">
        <span>
          ANC <b className="tabular-nums text-ink">{dash(h.ancCounts.total)}</b>
        </span>
        <span>
          ห้องคลอด <b className="tabular-nums text-ink">{dash(h.counts.total)}</b>
        </span>
        <span className="inline-flex items-center gap-1">
          พาร์โทกราฟ <PartoCell hospital={h} />

      </div>
    </Link>
  );
}
```

- The `ProvinceMap` `onSelect` prop is `(hcode: string | null) => void`, and `setSelected` matches it.
