# Ward Board + Patient Detail Redesign Implementation Plan (Sub-project 3 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (one implementer, end to end, in an isolated git worktree). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the two screens ward nurses use all shift on the direction-C foundation:
- the HOSxP-live ward board `/hospital-maternity-ward`;
- the patient detail page `/patients/[an]`.

They must be legible at 1024px (ward PC) and 768px (tablet). Risk colour comes only from tokens/`RiskChip`, labels are Thai-first, and empty states use `EmptyState`. Every error is actionable Thai. CPD and partograph-CDSS logic are untouched.

**Architecture:**
- **Rules:** ward-board rules move into one pure service, `src/services/ward-board.ts`:
  - stage classification;
  - room grouping;
  - one bed-counting rule, which fixes bug B1.
- **Copy and tones:** in config modules (`ward-display`, `obstetric-display`, `status-tone`).
- **Error copy:** pure functions in `src/lib/actionable-errors.ts` that feed `ErrorState`.
- **Pages:** both pages become compositions of foundation blocks.
- **Characterization tests first:** written before anything changes. Copy lives in one `COPY` table per test file, so restyle tasks can only change that table.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind CSS 4 (`@theme`, container queries), shadcn/ui + Base UI, SWR, @dnd-kit, lucide-react, Vitest + RTL (jsdom), Playwright (`page.route` BMS mock), ESLint 9 flat config.

**Spec:** `docs/superpowers/specs/2026-10-11-ui-ward-design.md`. Foundation: `docs/superpowers/{specs,plans}/2026-10-11-ui-foundation*.md`. Dashboard (patterns reused): `docs/superpowers/{specs,plans}/2026-10-11-ui-dashboard*.md`. Read the ward spec first.

### Spec deviations (decided while planning, with reasons)

The design-level deviations D1–D13 are in the spec. These are the plan-level ones:

1. **Characterization uses copy tables.** The board's copy changes language, so one file cannot pin both behaviour and today's English text. Every copy-dependent assertion goes through `COPY`. Numbers are matched with `^0?N$`, which accepts both today's zero padding and the new unpadded tiles.
2. **`WARD_BEDS_*` fixtures are shared** (`tests/helpers/ward-fixtures.ts`, type-only imports) by unit, integration and E2E tests. The E2E ward board and the unit tests then exercise the same nine-bed, two-room scenario: all four stages, nulls-last bed order, two locked beds.
3. **The E2E ward run mocks BMS with `page.route`**, not a tunnel. It mocks PasteJSON, the BMS `/api/sql`, the local-gateway probe (aborted), and `browser-push` (stubbed so mocked rows never reach the synthetic DB). This is how the board, which the 2026-10-11 visual review could not reach, gets visual verification at 1440/1024/768.
4. **`status-tone.ts` lands in Task 3** (with `StatusChip`), not Task 6. The chip needs it first; the patient panels reuse it.
5. **`StickyPatientHeader` uses a zero-height sticky anchor.** The bar is absolutely positioned inside a `sticky h-0` wrapper, so its appearance never shifts layout. Inserting a sticky bar of real height would push content down, re-trigger the IntersectionObserver, and flicker.
6. **`occupied` counts occupant rows**, as the page did, not distinct beds. Only the lock handling changes (B1), so data glitches (two admissions on one bed) keep today's count.

```ts
import type { BedOccupancyFull, BedSlot, MaternityWard } from '@/types/maternity-ward';

export const HOUR = 3_600_000;

/** Local wall-clock parts `msAgo` before `now`, in the shape HOSxP returns
 *  (regdate 'YYYY-MM-DD', regtime 'HH:MM:SS'). The app parses them as local time. */
export function localParts(now: number, msAgo: number): { date: string; time: string } {
  const d = new Date(now - msAgo);
  const p = (n: number) => String(n).padStart(2, '0');
  return {
    date: `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`,
    time: `${p(d.getHours())}:${p(d.getMinutes())}:${p(d.getSeconds())}`,
  };
}

  bedno: string,
```

```ts
// src/services/ward-board.ts
// Ward-board rules. This module is the one source for the KPI masthead, the
// room headers and the bed tiles (constitution IV), so they cannot disagree.
// Pure: `now` is always passed in, keeping the board render-pure.
//
// The values are the ones the board has always used. Any clinical change
// needs the clinical owner's sign-off, not a UI edit.
import type { BedOccupancyFull, BedSlot } from '@/types/maternity-ward';

/** Prolonged latent phase on the board: admitted at least `minHours` ago
 *  with the cervix still below `cervixBelowCm` cm, or never recorded. */
export const PROLONGED_LATENT_RULE = { minHours: 12, cervixBelowCm: 4 } as const;

/** Cervix (cm) at which the tile reads active, then transition. */
export const LABOUR_STAGE_CM = { activeFrom: 4, transitionFrom: 7 } as const;

export type LabourStageKind = 'prolongedLatent' | 'transition' | 'active' | 'latent';

type AdmitTime = Pick<BedOccupancyFull, 'regdate' | 'regtime'>;

/** Hours since admission. HOSxP's local date + time are parsed as local
 *  time; an unparseable date counts as 0 h, which never triggers an alarm. */
export function hoursSinceAdmit(o: AdmitTime, now: number): number {
  const ts = Date.parse(`${o.regdate}T${o.regtime ?? '00:00:00'}`);
  return Number.isFinite(ts) ? (now - ts) / 3_600_000 : 0;
}

export function classifyLabourStage(
  o: AdmitTime & Pick<BedOccupancyFull, 'last_cervix_cm'>,
  now: number,
): LabourStageKind {
  const cx = o.last_cervix_cm;
  if (
    hoursSinceAdmit(o, now) >= PROLONGED_LATENT_RULE.minHours &&
    (cx === null || cx < PROLONGED_LATENT_RULE.cervixBelowCm)
  ) {
    return 'prolongedLatent';
  }
  if (cx !== null && cx >= LABOUR_STAGE_CM.transitionFrom) return 'transition';
  if (cx !== null && cx >= LABOUR_STAGE_CM.activeFrom) return 'active';
  return 'latent';
}

export interface RoomGroup {
  roomno: string;
  room_name: string | null;
  room_display_number: number | null;
  beds: BedSlot[];
}

/** Rooms by display number then roomno; beds by bed_order (nulls last) then bedno. */
export function groupBedsByRoom(beds: BedSlot[]): RoomGroup[] {
  const map = new Map<string, RoomGroup>();
  for (const b of beds) {
    let g = map.get(b.roomno);
    if (!g) {
      g = { roomno: b.roomno, room_name: b.room_name, room_display_number: b.room_display_number, beds: [] };
      map.set(b.roomno, g);
    }
    g.beds.push(b);
  }
  for (const g of map.values()) {
    g.beds.sort((a, b) => {
      const ao = a.bed_order ?? Number.MAX_SAFE_INTEGER;
      const bo = b.bed_order ?? Number.MAX_SAFE_INTEGER;
      if (ao !== bo) return ao - bo;
      return a.bedno.localeCompare(b.bedno);
    });
  }
  return [...map.values()].sort((a, b) => {
    const ad = a.room_display_number ?? Number.MAX_SAFE_INTEGER;
    const bd = b.room_display_number ?? Number.MAX_SAFE_INTEGER;
    if (ad !== bd) return ad - bd;
    return a.roomno.localeCompare(b.roomno);
  });
}

export interface BedSummary {
  totalBeds: number;
  /** Occupant rows on these beds, including patients on a locked bed (B1). */
  occupied: number;
  free: number;
  /** Locked beds with nobody in them. */
  lockedEmpty: number;
  /** Locked beds that still hold a patient (B1). They are shown and counted as occupied. */
  lockedOccupied: number;
  prolongedLatent: number;
  /** Rounded % of beds occupied; null for a ward with no beds. */
  occupancyPct: number | null;
}

/**
 * The one counting rule for a ward or a room (B1). An occupant always counts
 * as occupied, even on a bed HOSxP has since locked. `lockedEmpty` counts only
 * empty locked beds, and free = total − occupied − lockedEmpty (never below 0).
 * Occupants whose bed is not in `beds` are ignored.
 */
export function summarizeBeds(beds: BedSlot[], occupancy: BedOccupancyFull[], now: number): BedSummary {
  const bednos = new Set(beds.map((b) => b.bedno));
  const occ = occupancy.filter((o) => bednos.has(o.bedno));
  const occupiedBednos = new Set(occ.map((o) => o.bedno));

  return {
    totalBeds,
    occupied,
    free: Math.max(0, totalBeds - occupied - lockedEmpty),
    lockedEmpty,
    lockedOccupied: locked.length - lockedEmpty,
    prolongedLatent: occ.filter((o) => classifyLabourStage(o, now) === 'prolongedLatent').length,
    occupancyPct: totalBeds > 0 ? Math.round((occupied / totalBeds) * 100) : null,
  };
```

```ts
// Turns raw failures into actionable Thai for ErrorState: what happened

// Constitution V: every user-facing error says what went wrong AND what to do.
export interface ActionableError {
  message: string;
  remedy: string;
  detail?: string;
}

const REOPEN = 'ปิดหน้านี้แล้วเปิด KK-LRMS จากเมนูใน HOSxP ใหม่อีกครั้งเพื่อสร้างเซสชันใหม่';

function errorText(err: unknown): string | undefined {
  if (err instanceof Error) return err.message;
  if (typeof err === 'string') return err;
  return undefined;
}

/** Messages thrown by retrieveBmsSession / extractConnectionConfig
 *  (src/lib/bms-browser-client.ts). Match on stable fragments, not full text. */
export function describeBmsSessionError(raw: string): ActionableError {
  const detail = raw;
  if (/missing bms_url/i.test(raw)) {
    return {
      message: 'เซสชัน HOSxP ไม่มีที่อยู่เซิร์ฟเวอร์ BMS ของโรงพยาบาล',

      detail,
    };
  }

    return {
      message: 'เซสชัน HOSxP ไม่มีรหัสยืนยันตัวตน',
```

```tsx
function fmtBodyMetrics(o: BedOccupancyFull): string {

/** Age of the maternal-screen assessment, from the tile's `now`
 *  (render purity: no Date.now() in render). */
function fmtScreenAge(assessedAt: string | null, now: number): string | null {
  if (!assessedAt) return null;
  const ms = Date.parse(assessedAt);
  if (!Number.isFinite(ms)) return null;
  const diffMin = Math.floor(Math.max(0, now - ms) / 60_000);
  if (diffMin < 60) return `${Math.max(1, diffMin)} นาที`;
  const diffHr = Math.floor(diffMin / 60);
  if (diffHr < 24) return `${diffHr} ชม.`;
  return `${Math.floor(diffHr / 24)} วัน`;
}

function fmtHours(regdate: string, regtime: string | null, now: number): string {
  const ms = Date.parse(`${regdate}T${regtime ?? '00:00:00'}`);
  if (!Number.isFinite(ms)) return '—';
  const diff = Math.max(0, now - ms);
  const h = Math.floor(diff / 3_600_000);
  const m = Math.floor((diff % 3_600_000) / 60_000);
  return `${String(h).padStart(2, '0')}:${String(m).padStart(2, '0')}`;
}

  if (!date && !time) return '—';

}
```

```ts
export function fmtDateTh(iso: string | null): string {
  if (!iso) return '—';
  return new Date(iso).toLocaleDateString('th-TH', { timeZone: 'Asia/Bangkok', year: 'numeric', month: 'short', day: 'numeric' });
}

export function fmtDateTimeTh(iso: string | null): string {
  if (!iso) return '—';
  return new Date(iso).toLocaleString('th-TH', {
    timeZone: 'Asia/Bangkok',
    year: 'numeric',
    month: 'short',
    day: 'numeric',
    hour: '2-digit',
    minute: '2-digit',
  });
}
```

```tsx
function AncTile({ label, value, note, tone }: { label: string; value: ReactNode; note?: string; tone: StatusTone }) {
```

```ts
// tests/e2e/helpers/mock-bms.ts
// Mocks the browser-direct HOSxP path for the ward board: PasteJSON session
// retrieval, the BMS /api/sql endpoint (first matching SQL substring wins,
// anything else returns []), the local-gateway probe (aborted so the app keeps
// the mock URL), and browser-push (stubbed so mocked rows never reach the
// synthetic DB). Every hit is logged for the debug attachment.
import type { Page, Route } from '@playwright/test';

export const MOCK_BMS_URL = 'https://bms-mock.e2e.invalid';
const CORS = {
  'access-control-allow-origin': '*',
  'access-control-allow-headers': '*',
  'access-control-allow-methods': 'GET,POST,PUT,DELETE,OPTIONS',
};

export interface MockBmsOptions {
  sql: Array<[string, unknown[]]>;
  omitBmsUrl?: boolean;
  log: string[];
}

export async function mockBms(page: Page, opts: MockBmsOptions): Promise<void> {
  await page.route('https://hosxp.net/phapi/PasteJSON**', (route) => {
    const user_info: Record<string, unknown> = {
      bms_session_code: 'e2e-bearer',
      loginname: 'e2e-nurse',
      fullname: 'E2E Nurse',
      hospcode: '10670',
    };
    if (!opts.omitBmsUrl) user_info.bms_url = MOCK_BMS_URL;
    opts.log.push(`mock-bms: PasteJSON (bms_url ${opts.omitBmsUrl ? 'omitted' : 'set'})`);
    return route.fulfill({
      status: 200,
      headers: CORS,
      contentType: 'application/json',
      body: JSON.stringify({ result: { user_info, key_value: 'e2e-bearer', expired_second: 3600 }, MessageCode: 200, Message: 'OK' }),
    });
  });
  await page.route('http://127.0.0.1:45011/**', (route) => route.abort());
  await page.route(`${MOCK_BMS_URL}/**`, async (route: Route) => {
    const req = route.request();
    if (req.method() === 'OPTIONS') return route.fulfill({ status: 204, headers: CORS });
    const path = new URL(req.url()).pathname;
    if (path === '/api/sql') {
      const sql = String((req.postDataJSON() as { sql?: string } | null)?.sql ?? '');
      const hit = opts.sql.find(([m]) => sql.includes(m));
      opts.log.push(`mock-bms: sql ${hit ? `"${hit[0]}" → ${hit[1].length} rows` : `unmatched: ${sql.slice(0, 60)}`}`);
      return route.fulfill({
        status: 200,
        headers: CORS,
        contentType: 'application/json',
        body: JSON.stringify({ data: hit?.[1] ?? [], MessageCode: 200, Message: 'ok' }),
      });
    }
    opts.log.push(`mock-bms: ${req.method()} ${path}`);
    return route.fulfill({
      status: 200,
      headers: CORS,
      contentType: 'application/json',
      body: JSON.stringify({ MessageCode: 200, Message: 'ok', Value: 0 }),
    });
  });
  await page.route('**/api/sync/browser-push**', (route) =>
    route.fulfill({ status: 200, contentType: 'application/json', body: '{}' }),
  );
}
```

```ts
// tests/e2e/helpers/layout-metrics.ts
// Page-level horizontal overflow and leaf text under the 13px floor (Leaflet
// attribution excluded; SVG text has no innerText and is measured separately).
import type { Page } from '@playwright/test';

export interface LayoutMetrics {
  scrollWidth: number;
  clientWidth: number;
  tinyText: string[];
}

export async function measureLayout(page: Page): Promise<LayoutMetrics> {
  return page.evaluate(() => ({
    scrollWidth: document.documentElement.scrollWidth,
    clientWidth: document.documentElement.clientWidth,
    tinyText: [...document.querySelectorAll('body *')]
      .filter((el) => (el as HTMLElement).innerText?.trim() && el.children.length === 0)
      .filter((el) => !el.closest('.leaflet-container'))
      .filter((el) => parseFloat(getComputedStyle(el).fontSize) < 13)
      .map((el) => `${el.tagName.toLowerCase()}: ${(el as HTMLElement).innerText.trim().slice(0, 40)}`),
  }));
}
```
